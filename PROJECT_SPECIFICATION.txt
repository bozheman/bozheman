1. ОБЩИЕ СВЕДЕНИЯ О ПРОЕКТЕ
--------------------------------------------------------------------------------
BOZHEMAN ≡ PROTOCOL — это интерактивный киберпанк веб-портал и мультимедийная 
экосистема стримера, разработчика игр и контент-мейкера BOZHEMAN.

Ключевые возможности портала:
- Интерактивная 3D-сцена и атмосферная терминальная эстетика.
- Игровой хаб (BOZHEMAN GAMES HUB) с анонсами проектов и Telegram-ботов.
- Встроенная мини-игра «BOZHEMAN SLOTS 777» с полноценным физическим движком.
- Секретный интерактивный протокол («ИЛЛЮЗИЯ») с пасхалками и лором.
- Финансовый блок поддержки: крипто-шлюзы, QR-коды, Steam-трейды, рефералы.
- Поддержка многоязычности (i18n) на 8 языках.
- PWA (Progressive Web App) функциональность для работы offline.

--------------------------------------------------------------------------------
2. ТЕХНОЛОГИЧЕСКИЙ СТЕК И АРХИТЕКТУРА
--------------------------------------------------------------------------------
2.1. Frontend Core:
     - HTML5 (семантическая верстка, OpenGraph & Twitter Card метатеги, Schema.org).
     - CSS3 (Custom Properties / переменные, Flexbox, CSS Grid, Glassmorphism, 
       Custom Keyframe Animations, Scanlines).
     - JavaScript ES6+ (чистый Vanilla JS с использованием ES-модулей `type="module"`).
     - Сборщики и транспайлеры HE используются (прямое подключение в браузерах).

2.2. Graphic & Animation Libraries:
     - Three.js v0.165.0 (подключение через CDN & importmap).
     - OrbitControls (трехмерное вращение объектов мышью/тачем).
     - TWEEN.js (плавные анимации свойств 3D-объектов).
     - Canvas 2D API (нативные движки матричного дождя, барабанов и частиц).

2.3. Backend & Cloud Integration:
     - Firebase JS SDK v10.8.1 (Firebase Auth через Google Provider, 
       Firestore Database для сбора заявок `interested_users`, Firebase Analytics).
     - Hosting: GitHub Pages (автоматический CI/CD деплой через GitHub Actions).

2.4. Audio & Micro-effects:
     - Web Audio API (генератор звуковых эффектов для слотов без внешних mp3/wav).
     - HTML5 Audio (фоновое эмбиент-сопровождение `omega.m4a`, `omega2.m4a`, `glitch.mp3`).

2.5. Utility Libraries:
     - QRious v4.0.2 (генератор динамических QR-кодов для криптовалютных адресов).
     - Google Fonts (Fira Code — моноширинный шрифт).

4. ОПИСАНИЕ СТРАНИЦ И ИНТЕРФЕЙСНЫХ МОДУЛЕЙ
--------------------------------------------------------------------------------
4.1. Главный терминал (`index.html` | `js/index.js` | `css/main.css`, `css/neon.css`):
     - Прелоадер с терминальным логом загрузки протокола и возможностью пропуска 
       (кликом мышью или клавишами Space / Enter / Escape).
     - Интерактивный 3D-объект Икосаэдр (Three.js IcosahedronGeometry), реагирующий 
       на клики вспышкой эмиссии.
     - Пасхалка Секретного Протокола: 10 кликов по 3D-объекту запускают глитч 
       аудио и экранный эффект распада `glitch-out`, после чего происходит 
       перенаправление на `doubleindex.html`.
     - Навигационный блок социальных сетей и сервисов (Twitch, Instagram, YouTube, 
       TikTok, Games Hub, Donation).
     - Фоновая анимация матричного дождя (`js/matrix.js`).
     - Плавающие элементы: выбор языка (`#lang-select`) и переключатель звука (`#sound-toggle`).

4.2. Игровой Хаб (`games.html` | `js/games.js` | `css/games.css`):
     - Заголовок с индикатором состояния системы (SYSTEM: ONLINE █ NODES: 3 █ PROTOCOL v6.2).
     - Интерактивная фильтрация проектов (ALL, TG BOTS, IN DEV, SOON).
     - Карточка карточка бота GrowerSim (#MOD-01): краткое описание, стек (aiogram 3, 
       Genetics, P2P Market, Cannabis Cup), прямая ссылка на бота `@GrowerSim_bot` 
       и модальное окно руководства.
     - Модальное окно руководства GrowerSim с динамическими вкладками (Profile, Garden, Shop) 
       и переходом к полной версии.
     - Модуль интерактивной авторизации через Google Firebase Auth с таймером обратного 
       отсчета до анонсов и сохранением емейлов подписчиков в Firestore.

4.3. Полная инструкция GrowerSim (`grower_manual.html` | `js/manual_full.js`):
     - Развернутая документация по 6 аспектам игры: Profile, Garden, Shop, 
       Genetics (аллели, гибридизация, мутация Quantum Strain x3), Market (P2P Биржа), 
       Cannabis Cup (сезонные турниры).

4.4. Финансовая поддержка и партнёры (`refer.html` | `js/refer.js` | `css/refer.css`):
     - Crypto Gateways: Кошельки USDT (TRC20), BTC, ETH (ERC20), BNB (BEP20).
     - Копирование адреса кошелька в буфер обмена в 1 клик с visual feedback.
     - Просмотр QR-кода адреса в модальном окне (библиотека QRious + fallback 2D Canvas).
     - Steam Protocol: Прямая ссылка на обмен скинами Steam.
     - Referral Systems: Ссылки на DMarket, CSGOEmpire, Swap.gg, Pricempire и инвентарь.

4.5. Слот-машина BOZHEMAN SLOTS (`roulet.html` | `js/roulette.js` | `css/roulet.css` + `js/engine/*`):
     - Игровой автомат 3x3 с символами: 7, ★, Ω, ▲, ■, —.
     - Архитектура State Machine: IDLE ➔ SPINNING ➔ EVALUATING ➔ REWARDING ➔ IDLE.
     - Модули движка slot-engine:
       * `js/engine/reel.js` — дельта-тайм визуализация вертикальной прокрутки 
         барабанов с размытием в движении (motion blur) и плавной доводкой (snap).
       * `js/engine/audio.js` — процедурный синтез звуков через Web Audio API 
         (клики, щелчки, вращение, выигрыш, джекпот, проигрыш).
       * `js/engine/particles.js` — система праздничных частиц при победе/джекпоте.
       * `js/engine/constants.js` — коэффициенты выплат (777 = x10, пара = x1.5 и др.).
     - Управление ставкой: кнопки +/-, быстрая установка (MIN, +50, +100, MAX), 
       поддержка прокрутки клавишей Пробел/Enter.
     - Автопополнение: кнопка "+ ПОЛУЧИТЬ 1000 МОНЕТ" появляется при балансе < 10.
     - Ведение истории операций и экранная тряска при проигрыше.

4.6. Секретный терминал «ИЛЛЮЗИЯ» (`doubleindex.html` | `js/doubleindex.js` | `css/doubleindex.css`):
     - Секретная страница, доступная при активации секретного протокола.
     - Вывод 7 философских фрагментов о Ткачах и Неорганическом Интеллекте 
       с эффектом печати по клику.
     - 60-секундный таймер обратного отсчета с прогресс-баром и авторедиректом на рулетку.

--------------------------------------------------------------------------------
5. ЕДИНАЯ СИСТЕМА УПРАВЛЕНИЯ СОСТОЯНИЕМ (STATE MANAGEMENT)
--------------------------------------------------------------------------------
Модуль `js/state.js` обеспечивает сохранность данных между страницами.
- Хранилище: `localStorage` по ключу `bzp_state_v2`.
- Структура состояния:
  {
    balance: 1000,
    audioMuted: true,
    secretUnlocked: false,
    rouletteStats: { spins: 0, wins: 0, totalWagered: 0, totalWon: 0 },
    lastBet: '',
    lastSeed: null
  }
- Защита данных: автоматическая проверка типов (Sanitization & Validation) 
  при загрузке, предотвращающая крах при некорректных значениях.

--------------------------------------------------------------------------------
6. СИСТЕМА МНОГОЯЗЫЧНОСТИ (I18N)
--------------------------------------------------------------------------------
Модуль `js/i18n.js` предоставляет локализацию интерфейса:
- Поддерживаемые языки: Английский (en), Русский (ru), Украинский (uk), 
  Белорусский (be), Польский (pl), Немецкий (de), Французский (fr), Испанский (es).
- Автоматическая подстановка переведенного текста по селекторам `data-i18n` 
  и атрибутам `data-i18n-attr`.
- Сохранение выбранного языка в `localStorage` (`bozheman_lang`).

--------------------------------------------------------------------------------
7. PWA И ОФФЛАЙН-РЕЖИМ
--------------------------------------------------------------------------------
- Файл `manifest.json`: описывает приложение для установки на мобильные устройства и ПК.
- Файл `sw.js`: Service Worker v1.0, кеширующий все HTML, CSS, JS и графические ресурсы. 
  Использует стратегию Stale-While-Revalidate для работы приложения без интернет-соединения.
