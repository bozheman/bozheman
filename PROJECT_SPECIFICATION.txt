1. ОБЩИЕ СВЕДЕНИЯ О ПРОЕКТЕ
--------------------------------------------------------------------------------
BOZHEMAN ≡ PROTOCOL — это цифровой веб-портал и мультимедийная экосистема
стримера, инди-разработчика игр и медиа-автора BOZHEMAN.

Ключевые возможности портала (v9.0):
- Презентационный портал: симметричная сетка из 8 равноправных навигационных
  кнопок (Twitch, Instagram, YouTube, TikTok, @GrowerSim_bot, Games Hub,
  Slots 777, Donation) без кричащей казино-рекламы и кислотных пульсаров.
- Интерактивное 3D-ядро (Three.js): багрово-красный металлический икосаэдр с
  внутренним рубиновым октаэдром, орбитальным кибер-кольцом и облаком частиц.
- Верхняя телеметрическая панель протокола (`#protocol-top-bar`) на всех страницах:
  статус узла (ONLINE), уникальный `Grower ID` (`#GRW-XXXXX`), кликабельный баланс
  монет протокола и ссылка на Telegram-бот `🌱 @GrowerSim_bot`.
- Интерактивный CLI-терминал (`[~] CLI`), доступный по клавише `~` (тильда) или кнопке в HUD:
  поддерживает команды `help`, `status`, `balance`, `daily`, `bot`, `grower`,
  `achievements`, `matrix`, `games`, `slots`, `export`, `import`, `hack`, `clear`.
- Модальное окно достижений протокола (`🏆 ACH`): 8 системных ачивок с прогресс-барами
  и вознаграждениями в протокольных монетах.
- Игровой хаб (`BOZHEMAN GAMES HUB`): карточки проектов (`GrowerSim`, `Project: Terminus`,
  `Project: Nebula`, `Slots 777`), живой поиск, фильтры и QR-код бота.
- Лабораторный симулятор Харвеста и Генетики Менделя (`grower_manual.html#harvest-calc`)
  с пресетами и расчетом Биомассы, концентрации ТГК, рыночной цены Bman и очков Cannabis Cup.
- Слот-машина «BOZHEMAN SLOTS 777»: физика вращения Canvas ReelEngine, синтез звуков
  через Web Audio API, Provably Fair SHA-256 сид, Turbo/Auto-Spin и ежедневный бонус.
- Секретный интерактивный протокол («ИЛЛЮЗИЯ»): 7 философских фрагментов Ткачей с печатью
  Typewriter, индикаторами чтения и наградой +500 монет за прочтение всех фрагментов.
- Финансовый блок поддержки: крипто-шлюзы (USDT TRC20, BTC, ETH ERC20, BNB BEP20)
  с копированием в 1 клик, генерацией QR-кодов, ссылками на обмен Steam и партнеров.
- Полная 100% локализация (315 ключей) на 8 языках (`ru`, `en`, `uk`, `be`, `pl`, `de`, `fr`, `es`)
  с декларативным связыванием (`data-i18n`, `data-i18n-html`, `data-i18n-attr`, `data-page-title`).
- PWA Offline-First (`sw.js` `bozheman-cache-v4`).

2. ТЕХНОЛОГИЧЕСКИЙ СТЕК И АРХИТЕКТУРА
--------------------------------------------------------------------------------
2.1. Frontend Core (Buildless Architecture):
     - HTML5 (семантическая разметка, Schema.org Person, OpenGraph, Twitter Cards).
     - CSS3 (Custom Properties / Design Tokens, Flexbox, CSS Grid, Glassmorphism).
     - JavaScript ES6+ Modules (прямое нативное подключение в браузерах без сборщиков).

2.2. Graphic & Animation Libraries:
     - Three.js v0.165.0 (CDN importmap).
     - OrbitControls (плавное 3D-вращение мышью и тачем).
     - TWEEN.js (сглаженные интерполяции свойств материалов и вращения).
     - Canvas 2D API (матричный дождь, барабаны слот-машины, праздничные частицы).

2.3. Backend & Cloud Integration:
     - Firebase JS SDK v10.8.1 (Firebase Auth Google Provider, Firestore Database `interested_users`).
     - Hosting: GitHub Pages (автоматический деплой через GitHub Actions).

2.4. Audio System:
     - Web Audio API (полный процедурный синтез звуков кликов, переходов, барабанов, побед и глитча).
     - HTML5 Audio (фоновые эмбиент-треки `omega.m4a`, `omega2.m4a`).

2.5. Utility Libraries:
     - QRious v4.0.2 (генерация динамических QR-кодов для кошельков и бота).
     - Google Fonts (Fira Code — моноширинный шрифт).

--------------------------------------------------------------------------------
3. ДИЗАЙН-СИСТЕМА: «СТРОГИЙ КИБЕР-ТЕРМИНАЛ»
--------------------------------------------------------------------------------
3.1. Основные цветовые токены:
     - Фоновый цвет: #000000 (Pure Black)
     - Поверхности: rgba(10, 4, 4, 0.65) / rgba(12, 6, 6, 0.92)
     - Границы: rgba(255, 51, 51, 0.22) / rgba(255, 51, 51, 0.48)
     - Основной акцент: #ff3333 (Cyber Crimson)
     - Приглушенный красный: #7a0000
     - Статус онлайн / успех: #00e575 (Terminal Emerald)
     - Золото / баланс: #e5b842 (Muted Gold)
     - Текст: #ffffff (White) и rgba(255, 110, 110, 0.7) (Muted Text)

3.2. Архитектурные правила умеренности (No-Clown Directives):
     - Отсутствие глобального размытия текста (`body { text-shadow: none }`).
     - Отсутствие агрессивных неоновых мигалок баланса на главной странице.
     - Отсутствие искажающих skewX-анимаций на кнопках.
     - Равный визуальный вес всех 8 элементов основной навигационной сетки.
