## 3. Автоматическое Обновление и Перезапуск Go-Сервера (Zero-Touch Auto-Restart)

Чтобы сервер на ноутбуке Ubuntu автоматически обновлялся и перезапускался после каждого пуша на GitHub без ручных команд:
1. **`internal/sync/github.go`:**
   - Фоновый цикл проверки каждые **`20 секунд`** (по умолчанию `BZP_AUTO_PULL=true`, `BZP_PULL_INTERVAL=20s`).
   - Делает `git fetch origin main` и сравнивает SHA (`HEAD` vs `origin/main`).
   - При наличии новых коммитов выполняет `git reset --hard origin/main`, пересобирает Go-бинарник (`go build -o bozheman-server.new ./cmd/server && mv ...`), закрывает сокет и вызывает **`syscall.Exec`** (`restart_unix.go`), бесшовно перезапуская процесс с новым кодом и новым Flutter Web фронтендом.
2. **`run_laptop_server.sh`:**
   - Супервизорный бесконечный цикл `while true` с авто-остановкой старых инстансов и немедленным перезапуском при любом выходе.
3. **Анти-кеш браузера (`cmd/server/main.go` + `web/index.html`):**
   - Строгие заголовки `Cache-Control: no-store, no-cache, must-revalidate, max-age=0` для `/`, `/index.html`, `/main.dart.js`, `/flutter_bootstrap.js`, `/flutter_service_worker.js`, `.json`.
   - Принудительное удаление старых Service Worker-ов в браузерах посетителей.
