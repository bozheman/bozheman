# План Разработки и Переноса Сайта «BOZHEMAN ≡ PROTOCOL» на Go + Flutter Web

> **Статус:** В работе (Активная миграция v10.0)  
> **Целевой стек:** Go (`go1.26` stdlib HTTP/API + GitHub Auto-Sync) + Flutter Web (`Flutter 3.50` / `Dart 3.14`)  
> **Среда эксплуатации:** Ноутбук-сервер с автоматической синхронизацией актуальной версии из GitHub (`git pull --ff-only`) + резервная совместимость со статическим хостингом (GitHub Pages).

---

## 1. Аудит Текущей Версии и Причины Переноса

### Проблемы старого сайта (Vanilla HTML/CSS/JS v9.0):
1. **Перегруженность главной страницы (`index.html`):**
   - Одновременно запускались: блокирующий прелоадер с печатью текста, фоновый `Canvas` матричного дождя, тяжелый WebGL-рендер Three.js (`Icosahedron` + `Octahedron` + `Torus` + `Points`), CRT-оверлей, 8 кнопок, баннер, нижний HUD, авто-всплывающие логи CLI-терминала и Service Worker.
   - При первом заходе пользователь не видел сразу четкой карты: куда перейти, зачем этот сайт и где соцсети.
2. **Размытое позиционирование для разных аудиторий:**
   - Посетители, пришедшие за ссылками на стримы и соцсети, отвлекались на сложные киберпанк-элементы.
   - Игроки, желающие просто покрутить бесплатные слоты («гемблинг ради гемблинга»), и пользователи, ищущие лор/симулятор `@GrowerSim_bot`, смешивались в одном перегруженном интерфейсе.
3. **Сложность поддержки 6 отдельных HTML-страниц и ручной синхронизации:**
   - 6 изолированных HTML-документов (`index.html`, `games.html`, `roulet.html`, `refer.html`, `doubleindex.html`, `grower_manual.html`) со своим дублированием HUD и стилей.
   - Отсутствие бэкенд-слоя на сервере для серверного Provably Fair, API расчетов и автоматического обновления с GitHub на ноутбуке-сервере.

## 2. Новая Архитектура «Три Потока» + Максимально Облегченная Главная

Главная страница (`/` — `HomeScreen`) максимально разгружается: **никакого тяжелого Three.js на входе, никакого блокирующего прелоадера, никакого визуального шума**. Чистый, быстрый, мгновенно загружаемый хаб в стандарте «Строгий Кибер-Терминал» (`#000000`, `#ff3333`, `#e5b842`, `#00e575`, моноширинная типографика).

Портал строится вокруг **трех четких маршрутов** для трех типов посетителей:

* **Что видят сразу на главной:**
  - Четкий блок **«МАГИСТРАЛЬ СОЦСЕТЕЙ»** с равновесными кнопками прямого перехода в 1 клик:
    - `Twitch` (`twitch.tv/Bozhemany`)
    - `YouTube` (`youtube.com/channel/UC_BgtvZc1dxQbJA1uEeFimw`)
    - `Instagram` (`instagram.com/bozheman`)
    - `TikTok` (`tiktok.com/@bozheman_`)
    - `Telegram Бот` (`@GrowerSim_bot` — `t.me/GrowerSim_bot`)
    - `Донат` (`donatello.to/bozheman`)
    - `Крипто-шлюзы и Steam` (`/support`)
    - `Игровой Хаб` (`/games`)
  - Быстрое копирование ссылки узла и QR-кода, чтобы делиться агрегатором.

### Поток 2: Гемблинг ради Гемблинга — Без Денежных Вложений (`Slots 777 Free-to-Play`)
* **Для кого:** Любители механики слотов, статистики и азарта без риска потерять реальные деньги.
* **Принципы модуля (`/slots`):**
  - **0% реальных денег:** только виртуальные кредиты протокола (`₿`), стартовый баланс `1000 ₿`, бесплатный рефилл `+1000 ₿` при обнулении и ежедневный бонус `+500 ₿`.
  - **Механика и азарт:** 3 анимированных барабана (CustomPainter на Flutter), режимы `TURBO` и `AUTO-SPIN`, настраиваемые ставки (`MIN`, `1/2`, `x2`, `+50`, `+100`, `MAX`), таблица выплат (`777 x10`, `★★★ x7`, `ΩΩΩ x5`, `▲▲▲ x3`, `■■■ x2`, `ЛЮБЫЕ 2 x1.5`).
  - **Честная математика:** Серверный генератор **Provably Fair SHA-256** на Go (`/api/v1/slots/spin`) с возможностью скопировать хеш/сид, живой статистикой (спины, винрейт, макс. куш, текущая серия) и историей транзакций.

## 4. Инфраструктура Ноутбука-Сервера (Auto-Update from GitHub)

Поскольку сайт работает на ноутбуке-сервере, который должен подтягивать актуальную версию с GitHub:
1. В Go-сервер встроен пакет `internal/sync/github.go`.
2. При старте с переменной окружения `BZP_AUTO_PULL=true` (включено по умолчанию в скриптах `run_laptop_server.*`):
   - Каждые `5 минут` (настраивается через `BZP_PULL_INTERVAL`) сервер вызывает `git fetch` + `git pull --ff-only` в рабочем каталоге.
   - Автоматически определяет путь к `git` (ищет в `PATH`, а на Windows также в `C:\Program Files\Git\cmd\git.exe`).
   - Отдает телеметрию обновлений через `GET /api/v1/sync/status` (текущий коммит, ветка, время последнего пулла, ошибки).
   - Поддерживает принудительный триггер обновления через `POST /api/v1/sync` (с поддержкой опционального секрета `BZP_SYNC_SECRET`, если нужно дергать из GitHub Webhook).
3. Поскольку скомпилированный Flutter Web бандл (`index.html`, `main.dart.js`, `flutter_bootstrap.js`, `assets/`) коммитится в репозиторий (или деплоится вместе с ним), сразу после `git pull` ноутбук-сервер начинает отдавать свежий фронтенд **без необходимости переустанавливать Flutter SDK на сервере**.
